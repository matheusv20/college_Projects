# Integer Singly Linked List

This project is focused on learning and implementing a **Singly Linked List of Integers** using the **C language**.

## 📁 Project Structure

The program is divided into two main parts:

* **Headers (.h):** Contains the structures and function prototypes (declarations).
* **Source Code (.c):** Contains the actual function implementations and the main.c file to run tests.

## 🛠️ Features Implemented

*   Creation of the Singly Linked List of Integers.
*   Basic operations: Node insertion and deletion (at head and tail).
*   Retrieval of boundary values (head and tail elements).
*   Display and inspection: (print all elements and count total elements).
